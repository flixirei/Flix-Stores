# Flix-Stores
# About
A very simple and clean script that allows you to create your own stores, such as pawnshops, and lets your players sell their items there!

# Features
 - Create unlimited custom stores

 - Set item prices and define store types (e.g., Pawnshop, Jewelry, etc.)

 - Easy to configure and use

# Requirements
 - [**ox_target**](https://github.com/overextended/ox_target)

 - [**ox_inventory**](https://github.com/overextended/ox_inventory)  

 - [**ox_lib**](https://github.com/overextended/ox_lib)
